# Module 4 · Active Directory Integration coverage

The [Okta Administrator Performance Exam Study Guide](https://certification.okta.com/page/administrator-performance-exam-study-guide) lists six objectives under Active Directory Integration, weighted at **47% of Part I**. The module includes the theory, an exercise per lesson, and an independent capstone. Use the supplied records to practice reasoning when the required lab hosts are offline.

| Exam objective | Theory and practice | Evidence |
| --- | --- | --- |
| Enable and manage delegated authentication with AD and LDAP | [AD activation and JIT](../../week-04-ad-and-ldap/lessons/03-activate-ad-users-and-configure-jit.md), [AD delegated authentication](../../week-04-ad-and-ldap/lessons/04-delegate-authentication-and-manage-agent-health.md), [Password authenticator](../../week-04-ad-and-ldap/lessons/05-manage-password-policy-and-directory-recovery.md), and [LDAP](../../week-04-ad-and-ldap/lessons/07-connect-ldap-and-delegate-ldap-authentication.md) | Credential test, fresh sign-in outcome, first-sign-in creation, Okta user and directory link. |
| Explain AD and LDAP agent architecture and practices | [Install and register](../../week-04-ad-and-ldap/lessons/01-connect-active-directory.md), [test AD failover](../../week-04-ad-and-ldap/lessons/04-delegate-authentication-and-manage-agent-health.md), [connect LDAP](../../week-04-ad-and-ldap/lessons/07-connect-ldap-and-delegate-ldap-authentication.md), and [operate the integrations](../../week-04-ad-and-ldap/lessons/09-operate-and-troubleshoot-directory-integrations.md) | Cloud and directory paths, Windows or LDAP runtime status, agent inventory, recovery evidence and logs. |
| Manage agent service accounts and reset permissions | [Agent setup](../../week-04-ad-and-ldap/lessons/01-connect-active-directory.md) and [scoped AD reset](../../week-04-ad-and-ldap/lessons/05-manage-password-policy-and-directory-recovery.md) | Service identity, its read and reset scope, successful reset, and fresh sign-in with the new credential. |
| Explain Okta and AD password policy requirements | [Password policy and recovery](../../week-04-ad-and-ldap/lessons/05-manage-password-policy-and-directory-recovery.md) | Compare provider, enforced AD requirements, Okta checks, recovery and lockout. |
| Explain activation options when AD is the source | [Import and match](../../week-04-ad-and-ldap/lessons/02-import-and-match-ad-users.md), [activate and compare JIT](../../week-04-ad-and-ldap/lessons/03-activate-ad-users-and-configure-jit.md), and [source-driven lifecycle](../../week-04-ad-and-ldap/lessons/08-manage-ad-profile-sourcing-and-lifecycle.md) | Proposed match, activation option, stored user status, sign-in and reactivation evidence. |
| Explain AD groups and Okta groups | [Import and push groups](../../week-04-ad-and-ldap/lessons/06-import-ad-groups-and-write-back-to-ad.md) | Source owner, OU scope, actual imported members, rule assignment and separate push group. |

The [capstone](hands-on-labs.md#capstone) combines the objectives. [Manage Profiles Lesson 10](../manage-profiles/10-follow-hr-sourcing-through-app-access.md) shows how an external HR system can own lifecycle while AD serves as a downstream target.
