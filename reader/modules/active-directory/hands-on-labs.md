# Module 4 · Active Directory Integration hands-on labs

Choose an exercise for its full instructions. Use the offline capstone records if your AD environment is disconnected.

## Choose a lab { #active-directory-lab-grid }

- [1. Connect Active Directory to Okta](#lab-1)

    Prepare the test AD domain, register the agent, and verify both network paths.

- [2. Import and match Active Directory users](#lab-2)

    Compare exact and partial matching, confirmation, and full and incremental imports.

- [3. Activate AD users and configure Just-In-Time provisioning](#lab-3)

    Compare staged activation, first-sign-in creation, and OU boundaries.

- [4. Delegate AD authentication and manage agent health](#lab-4)

    Run a delegated password sign-in and verify failover across agent hosts.

- [5. Manage password policy and directory recovery](#lab-5)

    Compare policy enforcement and prove a scoped AD password reset.

- [6. Import AD groups and write data back to AD](#lab-6)

    Trace imported membership and test user and group writes to AD.

- [7. Connect LDAP and delegate LDAP authentication](#lab-7)

    Configure the LDAP agent, import profiles, and verify delegated sign-in.

- [8. Manage AD profile sourcing and lifecycle](#lab-8)

    Compare source priority, suspension, deactivation, and reactivation.

- [9. Operate and troubleshoot directory integrations](#lab-9)

    Locate a scoped import failure and audit agent maintenance evidence.

- [Capstone · Onboard, secure, and offboard directory users](#capstone)

    Verify the complete integration and diagnose a failure.
