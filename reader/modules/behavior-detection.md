# Module 5 · Behavior Detection

Learn how Okta decides whether a sign-in context is familiar, how an app policy uses that signal, and how to prove which rule applied. Behavior Detection accounts for **30% of Part II** in the Okta Administrator Performance Exam study guide. [Official study guide](https://certification.okta.com/page/administrator-performance-exam-study-guide)
