# Module 5 · Behavior Detection hands-on labs

Start after reading the [module theory](../behavior-detection.md). Each lab builds on the previous configuration. When you can explain the rule selected for each sign-in, open the [practice use cases](practice-use-cases.md).

## Choose a lab { #behavior-detection-lab-grid }

- [1. Enroll and verify mobile Okta Verify](#lab-1)

    Set up the test users and verify Push on a mobile device.

- [2. Configure a group-scoped behavior rule](#lab-2)

    Connect a named device behavior and a test group to an app's sign-in requirement.

- [3. Modify the Catch-All Rule](#lab-3)

    Configure the fallback and check which requests and apps receive it.

- [4. Test the policy and read the System Log](#lab-4)

    Compare familiar, unfamiliar, and outside-group sign-ins using policy evidence.

- [Practice use cases and capstone](practice-use-cases.md)

    Build the policy independently and repair a broken test.
